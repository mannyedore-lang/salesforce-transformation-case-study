# Salesforce Transformation Case Study

A recruiter-friendly case study showing how a global CRM transformation can be managed as a business and technology program.

## Scenario

A global organization needs a scalable CRM operating model across 127 facilities while balancing regional requirements, service delivery, governance, adoption, and cost.

## Program Objectives

- Standardize core CRM capabilities while allowing necessary regional variation
- Automate service workflows
- Improve KPI visibility
- Strengthen release governance
- Reduce operating cost
- Improve user adoption and supportability

## Illustrative Outcomes

- Global operating model established
- Service workflows automated
- KPI-driven dashboards introduced
- Release governance strengthened
- IT OPEX reduced by 40%

> Note: This repository is a portfolio case study and contains no confidential employer data.
